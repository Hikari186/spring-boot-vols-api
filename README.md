# API de réservation de vols

  Un petit projet Spring Boot que j'ai réalisé pour pratiquer la création d'une API REST de bout en bout : entités JPA, services, contrôleurs, validation, gestion des erreurs et tests.

  L'idée est simple : on peut créer des vols, les consulter, et réserver une place sur un vol tant qu'il en reste.

  ## Technologies

## Technologies

- Java 21
- Spring Boot 4 (Web MVC, Data JPA, Validation)
- H2 (base de données en mémoire)
- JUnit, Mockito, AssertJ et MockMvc pour les tests
- Gradle

## Lancer le projet

```bash
./gradlew bootRun
```
